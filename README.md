# AP Computer Science Principles Pseudocode Practice
## AP Computer Science Principles
AP Computer Science Principles is an introductory Computer Science course that teaches the basics of a coding language (Up to a teacher's discretion, Round Rock High School commonly uses Python) and uses its own pseudocode language for the AP exam.
## The Repository
This repository contains all the pseudocode practice I do to prepare for the AP Computer Science Principles exam on May 14th of 2027. All pseudocode in this repo uses the official APCSP pseudocode syntax.
## When I Took AP Computer Science Principles
I took AP Computer Science Principles for the 2026-2027 academic school year as a freshman (9th grader) in high school.
